Install Cajuí firmware

Version {{VERSION}} for the Heltec WiFi LoRa 32 V3. Connect the board by USB and use Chrome or Edge on a computer; the browser asks which serial port to use.

Receiver

Keeps its enrollment, settings and queued samples.

Also erases stored data. Use it for a board that never ran Cajuí, or to start over.

Transmitter

Keeps its enrollment and counters.

Also erases stored data. The board then pairs by radio: hold its PRG button for three seconds.

Good to know

A receiver can also be updated without a computer: download its .cjfw file from the releases and install it from the receiver's setup page.

Erasing a board that was already enrolled discards its keys for good; pair it again afterwards. Downgrading a receiver that stored samples with a newer version needs its storage reset; see the update documentation.
