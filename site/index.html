What installing does

It writes the bootloader, the partition table and the application. It never erases the cajui storage partition, so an updated device keeps its enrollment, counters and queued samples. A new device starts in administration mode and joins a network by radio pairing or USB enrollment.

A receiver can also be updated without a computer: download its .cjfw file from the releases and install it from the receiver's setup page. Downgrading a receiver that has already stored samples with a newer version needs its storage reset; see the documentation.
